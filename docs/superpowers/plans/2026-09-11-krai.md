# KRAI implementation plan

**Goal:** Deliver the Ukrainian editorial Carpathian atlas described in the supplied brief.
**Architecture:** Static Next.js export. Server-composed editorial spreads, narrowly scoped client islands for map, recording simulation, archive filtering and scroll effects. All assets and data are local.
**Tech stack:** Next.js, TypeScript, React, CSS with native animation and IntersectionObserver.
**Spec:** `DESIGN.md` and the supplied KRAI brief.
